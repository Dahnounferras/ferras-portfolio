# ferras-portfolio

Personal site — software engineering + digital and 35mm film photography.
Built with [Astro](https://astro.build), deployed on Vercel.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # static site in dist/
```

Requires Node 22.23+.

## Editing content

| What | Where |
| --- | --- |
| Name, intro, email, social links, gear | `src/data/site.ts` |
| Bandwidth roles (timeline) | `src/data/roles.json` — dates only; bars + durations are computed at build |
| Side projects | `src/data/projects.json` — add an entry and it replaces an "Unexposed" slot |
| Portrait | replace `src/assets/portrait.jpg` (any size, 4:5 crop) |

## Adding photos

**Digital** — drop JPG/PNG/WebP files straight off the camera into `src/photos/digital/`.
That's it. Camera, lens, focal length, aperture, shutter, ISO and year are read from each
file's EXIF at build time, and photos are sorted newest first.

Optionally add a title or place in `src/photos/digital/photos.json`, keyed by file name:

```json
{ "DSC01234.JPG": { "title": "Golden hour", "place": "Raleigh" } }
```

Anything there overrides EXIF (e.g. `"lens": "Helios 44-2"` for a manual lens that writes no EXIF).

**Film** — one folder per roll in `src/photos/film/` (e.g. `roll-03/`), containing the scans
plus a `roll.json`:

```json
{ "title": "Roll 03", "stock": "Portra 400", "camera": "Pentax K1000", "date": "Nov 2026", "notes": "optional" }
```

Frames are ordered by file name and get film-edge numbers (1, 1A, 2, 2A…). Newest roll
(highest folder name) shows first on the archive; `roll-01` is the home-page strip.

**Privacy:** every published image is re-encoded by Astro/sharp, which strips all metadata —
GPS coordinates never reach the live site. Because this repo is public, a pre-commit hook
(`.githooks/pre-commit`, enabled by `npm install`) also removes GPS location from the
original JPEGs you commit, losslessly, keeping lens/exposure data. Run `npm run strip-gps`
to clean everything under `src/` manually. Only JPEGs are checked — export other formats as
JPEG or make sure they carry no location.

**Placeholders:** the files named `placeholder-*.jpg`, `frame-0*.jpg` and `portrait.jpg` were
generated by `npm run placeholders`. Delete them as you add real photos.

## Deploying

1. Push this repo to GitHub.
2. In Vercel: **Add New → Project**, import the repo, deploy (Astro is auto-detected).
3. Every push to `main` redeploys; branches get preview URLs.
4. Custom domain: Vercel → Project → Settings → Domains, then update `site` in `astro.config.mjs`.

Note: the timeline's "PRESENT" bar and durations are computed at build time, so they refresh
whenever you deploy.

## Structure

```
src/
  data/          site.ts, roles.json, projects.json
  photos/        digital/ and film/<roll>/ — drop-in photo folders
  lib/           photos.ts (EXIF pipeline), timeline.ts (to-scale career axis)
  components/    Nav, SectionHeader, Timeline, ProjectFeature, UnexposedSlot,
                 ContactSheet, Sprockets, PhotoFrame, Footer
  layouts/       Base.astro
  pages/         index, photography, 404
  styles/        global.css — colors, type, spacing as CSS variables
```
